# Final DSR to Replenishment Report Copy Map

Reviewed formats: Jalandhar Final DSR and Kunda-style Replenishment Study.

| Replenishment section | Final DSR source | Builder handling |
| --- | --- | --- |
| Cover identifiers | Cover/project metadata | Auto-fill; confirm year, block and applicant. |
| Introduction and statutory background | Preface and Chapter 1 | Direct-copy common background; add current study purpose. |
| Physiography, climate and drainage | Chapters 4-5 | Direct-copy eligible. |
| Geology, mineral description and hydrogeology | Chapter 6 | Direct-copy eligible as baseline context. |
| Deposition of minerals | Chapter 3 | Direct-copy eligible. |
| Flora and fauna | Chapter 4 | Direct-copy eligible as baseline context. |
| Reserve / baseline replenishment | Chapter 7 | Reuse only for the same block and survey period. |
| EMGSM text | Chapter 1 / Annexure A | Direct-copy guideline text; current evidence is uploaded. |
| Maps and coordinates | Plates I-V / Annexure F | Reuse only for a matching block. |
| Pre/post survey, drone/DGPS/GCP | Not stable DSR content | Upload required. |
| Orthomosaic, DEM/DSM/DTM, point cloud | Not stable DSR content | Upload required. |
| Grid RL, volume and replenishment calculation | Not stable DSR content | Upload required. |
| Conclusion and current annexures | Different report scope | New text and uploads required. |

The builder shows this as the **Final DSR copy plan**. Green entries are reusable;
amber entries require current-study evidence and are never copied silently.
